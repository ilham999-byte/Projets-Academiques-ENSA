# 📚 Projets Académiques - ENSA El Jadida

Ce dépôt regroupe l'ensemble des travaux pratiques (TP) et projets réalisés durant mon cursus d'ingénieur à l'**École Nationale des Sciences Appliquées (ENSA) d'El Jadida**. 

Il témoigne de mon apprentissage progressif des technologies Java, du développement Fullstack et des architectures microservices.

---

## 🛠 Technologies Explorées

- **Langages :** Java (JEE), JavaScript, SQL, HTML/CSS.
- **Frameworks Backend :** Spring Boot, Hibernate (ORM), JPA.
- **Frontend :** React.js, Thymeleaf.
- **Architectures :** REST API, Microservices (gRPC), Pattern DAO.
- **Bases de données :** MySQL, PostgreSQL, H2.

---
